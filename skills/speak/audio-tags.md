# Audio tag whitelist

These are the only audio tags `speak` may use. Do not invent others. `scripts/speak.py` reads this file and refuses to speak text that contains a bracketed tag that is not listed here.

Each tag is one bullet of the form `- [tag]`.

## Emotion

- [weak]
- [angry]
- [bored]
- [menacing]
- [playful]
- [tired]
- [excited]

## Vocalizations

- [clears throat]
- [coughing]
- [chuckling]
- [sighing]
- [sniffling]
- [yawning]
- [laughing]
- [sharp exhale]
- [scoffing]
- [humming]
- [panting]
- [gasping]

## Delivery

- [whispering]
- [singing]
- [slowly]
- [softly]
- [pause]
- [voice breaking]

## Character

- [sleepy drowsy voice]
- [witch voice]
- [drunken voice]

## Sound effects

- [keyboard typing]
- [echoing]
- [knocking on door]
- [bell ringing]
- [phone ringing]
- [dog barking]
- [crowd cheering]
- [applause]
- [rain falling]
- [drum roll]
- [heartbeat]
- [engine starting]
